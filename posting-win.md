# 📢 Release-Information: Cachy-Sched-Pilot v1.2.0 (Windows / Cross-Platform Reference)

> **Hinweis / Note:**  
> Cachy-Sched-Pilot ist ein spezialisiertes Linux-Systemwerkzeug für den Linux-Kernel, CachyOS und Arch Linux (sched-ext / eBPF). Unter Windows dient dieses Dokument als Informations- und Dokumentationsreferenz für Cross-Platform-Entwickler und WSL2-Kernel-Tuner.

## Feature Overview
- **Kernel CPU Scheduler Telemetry**: Live inspection of Linux CPU schedulers, sysfs properties, and per-core utilization.
- **sched-ext (SCX) Hot-Swapping**: Fast on-the-fly switching between kernel schedulers and dynamic eBPF schedulers.
- **Privilege Separation**: Unprivileged frontend, Polkit backend helper.
- **Full Localization**: English and German.
- **Headless Automation**: JSON API for system scripts.
